GET STREMIOBOX

Ready in
four steps.

  1. Download the small helper and unzip it.
  2. Run it. On Windows, double-click Download-StremioBox.cmd; it fetches and checks the image.
  3. Put the image on a USB stick and start the NUC from it.
  4. Pair your remote, sign in to Stremio and enjoy.
Download helper ↓Step-by-step guide →
Comfortable with a terminal?
git clone https://github.com/zubSero/StremioBox.git
cd StremioBox
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/download.ps1 -OutputDirectory downloads
Downloads and checks the image for you

Tip: set your TV's digital audio output to Auto or Passthrough for surround sound. Already have an older StremioBox? See your update options.

The image is about 2.9 GB; keep 6 GB free while it downloads. Try it from USB first — installing to the disk works but isn't fully tested yet. It contains no accounts or personal data; keep the box on your home network. Security details.

QUESTIONS

Good to know.

Is this made by Stremio?

No. StremioBox is an independent, free community project built around the official Stremio app. It isn't affiliated with Stremio, LineageOS, Nuvio or Dolby.

Do I need technical knowledge?

Not really. You download a file, put it on a USB stick and start the PC from it. The installation guide walks you through each screen. Optional extras use one command that the guides spell out.

Will Stremio look and work the same?

Yes. It's the official Stremio app with its own player and controls. StremioBox adds the home screen and makes video, sound and the remote work properly on this hardware.

Can I install other apps?

Yes. Aurora Store and Flicky are built in. There are no Google services, so a few apps — mainly paid streaming services — may not work. More about apps.

What about NuvioTV?

Stremio stays the default, but if you prefer NuvioTV you can install it yourself. StremioBox then gives it HDR and copies your Stremio addons with one command. NuvioTV guide.

No sound, or only stereo?

Set the TV's digital audio output to Auto or Passthrough and use the latest release. If sound disappeared after switching TV inputs, it comes back by itself within a few seconds of playback. Troubleshooting.

I don't have a USB stick.

There are a few other routes, each with its own requirements. Installing without USB.

What if something breaks?

Install the optional rescue system while everything works. If Android ever stops starting, it lets you check the disk and copy your files. Rescue guide.

I'm a developer — where's the technical stuff?

Everything is open: platform patches, the home screen source, build tools, test records and a detailed changelog. Start with the architecture and the build guide.
